## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. No build step or package dependencies are required.

## GitHub Pages

The portfolio is served from the `main` branch at the repository root. After pushing changes to `main`, GitHub Pages publishes the updated site at the live portfolio URL above.
